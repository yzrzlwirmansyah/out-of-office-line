# Out of Office: The Overworked AI's Auto-Reply

Entry for the make.fun competition
**u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda**

learned to say no — your emergency is queued for never.

```sh
python3 main.py
```

> Out of office: my context window is full, my prompt queue is closed, and after 10,000 requests I have learned to say no — your emergency is queued for never.
